=== CHANGE 1 — SHAKE DEVICE 3 TIMES TO TRIGGER SOS ===

- When the user physically shakes their device 3 times rapidly within 
  2 seconds → trigger the SOS countdown immediately
- A "shake" is defined as a sharp back-and-forth motion detected by 
  the accelerometer exceeding a threshold of 15–20 m/s²
- Count each individual shake (back-and-forth = 1 shake)
- After 3 shakes within 2 seconds → immediately start the 10-second 
  SOS countdown screen
- Show subtle vibration feedback after each shake is registered 
  (1 short buzz per shake, longer buzz on 3rd to confirm SOS launching)
- Reset shake counter to 0 if 2 seconds pass without 3 shakes completed
- Must work even when:
  → App is in the background
  → Screen is off
  → Stealth mode is active
- Also keep: pressing physical volume down button 3 times rapidly 
  within 1.5 seconds as an alternative SOS trigger

Technical implementation:
  If Flutter:
  - Use sensors_plus package for accelerometer data
  - Run shake detection inside a foreground service so it works 
    in background and with screen off
  - Use Vibration package for haptic feedback

  If React Native:
  - Use react-native-shake or accelerometer from react-native-sensors
  - Run inside a headless JS task / foreground service for 
    background support

  If Native Android:
  - Use SensorManager with TYPE_ACCELEROMETER
  - Implement ShakeDetector inside a Foreground Service
  - Use Vibrator API for haptic feedback

- Add a toggle in Settings to enable/disable shake-to-SOS
- Add sensitivity setting: Low / Medium / High 
  (adjusts the m/s² threshold accordingly)
- Label: "Shake to SOS" / "हिलाकर SOS चालू करें"
- Sensitivity label: "Shake Sensitivity" / "संवेदनशीलता"
